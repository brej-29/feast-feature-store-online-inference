# Feature Catalog

This file is generated by the script `scripts/export_feature_catalog.py`.

To regenerate after changing Feast entities, FeatureViews, or FeatureServices, run:

```bash
python scripts/export_feature_catalog.py
```

The script introspects the Feast repo under `feature_repo/` and documents:

- Entities and join keys
- FeatureViews and their feature schemas
- FeatureServices and which views/features they include
- Data source paths for each FeatureView
